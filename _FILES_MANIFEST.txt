HOW TO USE
──────────

STEP 1: Test locally
  $ cd [project-directory]
  $ pip install -r requirements.txt
  $ streamlit run erjor_ae_dashboard.py
  
  → Opens at http://localhost:8501
  → Try: enter "Frost" in sidebar → should show Rank #1, 25 reviews

STEP 2: Deploy for sharing
  Option A (Easiest): Streamlit Cloud
    - Push to GitHub
    - Connect at share.streamlit.io
    - Get public URL → share with AEs

  Option B: Self-hosted (Docker)
    - docker build -t erjor-ae .
    - docker run -p 8501:8501 erjor-ae

  Option C: Keep running locally on institution server

STEP 3: Share with AE community
  - Send dashboard URL
  - Brief instructions: enter surname → see metrics & papers
  - Note: rankings anonymous for other users

ANONYMIZATION STRATEGY
──────────────────────

✓ Default view: Anonymized rankings (Rank 1, Rank 2, ... Rank 71)
  → No names visible to other users
  → Anyone can see distribution

✓ Individual identification: Surname match (case-insensitive)
  → Each AE enters their surname
  → System reveals only their data & position
  → Highlighted in rankings table

✓ Privacy: No passwords/2FA required (assumes closed AE community)
  → Can upgrade to token/PIN if needed
  → Instructions in DEPLOYMENT_GUIDE.md
